# Suave Elite Barbershop Website

A premium, single-page website for **Suave Elite Barbershop** in Old East Dallas, Dallas, TX.

## Features

- Clean, high-end dark & gold aesthetic tailored for discerning clients
- Full service menu with pricing sourced from Booksy
- Grooming products section
- Barber team profiles
- Client testimonials highlighting 4.7+ Google rating
- Contact info, hours, amenities, and embedded map
- Mobile-responsive with smooth scroll animations
- Direct booking links to Booksy

## Quick Start

Open `index.html` in a browser, or serve locally:

```bash
python3 -m http.server 8080
```

Then visit `http://localhost:8080`.

## Structure

```
├── index.html       # Main page
├── css/styles.css   # Styles
└── js/main.js       # Interactions & animations
```
