# Suave Elite Barbershop Website

A clean, high-end marketing site for **Suave Elite Barbershop** in Dallas, TX.

## Quick start

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
npm run preview
```

## Details included

- Address, phone, hours, Instagram, and Booksy booking
- Full service menu with prices from public Booksy listings
- Google 4.7+ review positioning and client quotes
- Responsive layout tailored for premium clientele
