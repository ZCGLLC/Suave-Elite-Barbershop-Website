# Suave Elite Barbershop

A clean, classy website for [Suave Elite Barbershop](https://www.google.com/search?q=Suave+Elite+Barbershop) in Old East Dallas.

## Pages

- `index.html` — Home, products, barbers, reviews, visit, and booking
- `services.html` — Full service menu compiled from the house Booksy books

Open `index.html` in a browser, or serve the folder locally:

```bash
python3 -m http.server 4173
```

Then visit `http://localhost:4173`.
